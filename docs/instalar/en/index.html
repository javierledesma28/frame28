Install Frame28 without the pain.

This page recognises your system (in your browser; nothing is sent anywhere), gives you the exact line and tells you what you will see. The installer is interactive: it says which step it is on, why, and asks before each thing. It works on a brand-new computer.

1 · Copy this line

irm https://frame28.t28.io/install.ps1 | iex

Works on Windows 10 and 11. If you would rather read the script before running it, open it here.

2 · Paste it into a terminal

  1. Press the Windows key, type “Terminal” and open it.

    A dark window with a cursor appears. That is normal.

  2. Paste the line (right-click or Ctrl+V) and press Enter.

    The installer introduces itself, tells you what it will install and asks “Shall we start?”. Press Enter to go on.

  3. Wait and answer.

    Each step explains why it is there. If something fails, it offers to retry, skip or quit. Between 5 and 15 minutes. (The installer speaks Spanish for now.)

  4. Close the terminal, open a new one and type claude.

    Sign in with your Claude account. Only the first time.

  5. Sign in with your Frame28 account: in the terminal, type claude mcp login plugin:frame28:frame28.

    Your browser opens: your email and the code you receive, no password. If you do not have a Frame28 account yet, it is created right there, for free (it edits in demo mode with the Frame28 brand). Then open a new Claude Code session, in the terminal or in the desktop app: Frame28 shows up in sessions started after you sign in. If the terminal does not know login, type claude update first, or sign in with claude → /mcp → frame28 → Authenticate.
