## What you'll learn

- What a workstation needs and how it's installed in ten minutes.
- The first edit end to end, on screen.
- How to ask for changes and how to get shorts and languages.

## Script outline

1. **Hook.** "Ten minutes to install. After that, the video never leaves your company."
2. **What a workstation needs.** A normal computer, Claude Code for whoever directs, internet to install.
3. **Installing, on screen.** The one-line installer; what it asks; `frame28 doctor` at the end and what each line means.
4. **Your brand.** Already configured; how to see it and how to regenerate it from the website if it changes.
5. **The first edit.** Folder with the clip; "Here's my clip, edit it with brand X"; what Claude asks;
   transcription, cuts, edit script; render; contact sheet.
6. **Asking for changes.** In plain language: "the title at 1:10 shorter", "remove the counter". What gets regenerated.
7. **Shorts and languages.** "Give me three shorts with two hooks each." "Spanish version."
8. **When something fails.** New terminal, network for the render, proper nouns, doctor.
9. **Closing.** The two training sessions and support.

## Key lines

## What the edit puts on screen

Screen recording with the terminal and Claude Code as a window next to the speaker; numbered steps; a symptoms and
fixes table at the end.

## Homework

Install Frame28 on one workstation with the installer, run `frame28 doctor` and send the screenshot to support if
anything shows in red.
